4 LLM 意图引擎（推荐开启，更懂人话）

聊天先由大模型理解用户意图（再查数），失败自动回退规则引擎。两种提供方任选其一：

DeepSeek：Base URL 填 https://api.deepseek.com，模型 deepseek-chat；Ollama：Base URL 填 http://127.0.0.1:11434，模型填已拉取的模型名（如 qwen2.5:7b）

5 写码车道（本机 Cursor Local）

对齐 simplified「写码车道」：在本机工程目录用 Cursor SDK Local Agent 改码（沙箱同步）。 默认关闭；开启并保存后，可用功能插件 code-dev / 工具 mes_code_dev_*。 不会自动 git commit / push / 部署。

需已安装 Python 包 cursor-sdk；改完点下方「保存全部配置」后立即生效（无需重启引擎）。

6 审码车道（本机直读）

对齐 simplified 本机审码：直读本地源码 + LLM 出 findings；不用 Git、不用 VS Code Bridge。 在工作助手对话中说「审核代码 /Users/你/项目」即可触发；Agent 工具 mes_code_review_*。
依赖配置中心 LLM（DeepSeek / Ollama）；改完点「保存全部配置」后生效。

7 提交车道（人触发）

对话说「提交代码」→ 选目录 → 门禁（仅 P0/P1 阻断列表）→ 人确认后才 git commit/push。 Agent 工具 mes_code_commit_*；模型不会执行 git。
另需在「功能插件」中保持 人触发提交 / code-commit 开启。
改完点「保存全部配置」后生效；禁止直接提交到 main/master。

8 自动化部署

境外 Git 无法走 Actions 时用本机 SSH：按插件增量 rsync 到预发。对话「部署到预发」→ 勾选插件 → 人确认。 模型不会执行 SSH；须保持功能插件 code-deploy 开启。

本机按插件打包后 SSH/rsync 到预发（适合境外 Git / CI 连不上国内机）。
