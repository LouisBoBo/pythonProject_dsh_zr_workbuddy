### 2.3 写码进度卡：思考过程（晚间主线）

对照 Cursor 对话：要过程、要说明，不要干等、不要路径墙。

1. **无思考**：SDK 未开 `enableDeltas`/`enableSteps`，流异常被 `except: pass`；`live_text` 空。打开增量回调，任务开始即出思考框。  
2. **有字但重复、4 秒就「已完成思考」**：第一轮 `thinking-completed` 提前收起卡片；`text-delta` 当纯追加叠成双份；SSE 事件与 `live_text` 各推一次。改为结束前一直「思考中」；快照去重；SSE 约 0.25s。  
3. **工具绝对路径刷屏**：思考正文混进 `▸ 工具 /Users/.../sandboxes/...`。思考框只留中文叙事；动作用「阅读 `相对路径`」一行；改动说明 Markdown 渲染（表/标题/列表）；prompt 要求交付说明含结论、改动表、验收步骤。

桌面引擎与仓库引擎两套进程，改 Python 必须重启对应端口。

## 3. 踩坑表

| 现象 | 原因 | 处理 |
|------|------|------|
| 一体包提交失败缺模块 | `build_runtime` ignore 把 `code_*` 当缓存目录 | 校验 `code_dev/review/commit/deploy/hitl` 必进包 |
| 选目录 -1743 | osascript 控 Finder，一体包无自动化授权 | Electron `pickFolder` IPC（仅回环） |
| 插件市场要全局 pnpm | 包内 Node 不能写系统目录 | 内嵌 pnpm.cjs + 可写 `PNPM_HOME` |
| 部署成功界面不变 | 8090 是构建产物不是 Vite 源码 | 部署前 build，同步 `frontend/dist` |
| 接口仍 404 | systemd 服务未随 rsync 起来 | 白名单 `systemctl/supervisorctl/service restart` + 探活 |
| 写码 2 分钟无过程 | 未开 SDK 增量；吞掉 stream 异常 | `SendOptions(on_delta, on_step)`；异常打到进度 |
| 「已完成思考（4秒）」后干等 | 多轮 think-tool 把 duration 过早下发 | 仅任务结束才标耗时 |
| 思考区全是沙箱绝对路径 | `composed_think` 拼 tool 行；UI 再把 tool 追加进 thinkAcc | 思考与工具分栏；路径相对化；隐藏仓内引擎路径 |
