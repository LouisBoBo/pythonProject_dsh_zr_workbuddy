- 根因摘要：同一 Key 出现在本机 `config.yaml`、`~/.dsh/.credentials.yaml`、其它项目 `.env`，以及远端 `175.178.238.31` 的 DSH 凭据；公网 `https://…:8093/` 聊天入口在用。  
- 处理：远端备份后清空 DSH Key、挪 bak、iptables DROP 8093；控制台作废旧 Key、本机换新 Key（**禁止**空 Key 写进 DSH 凭据导致宿主起不来）。  
- 口径：引擎 SPA Key 字段空 ≠ 聊天未消耗。

## 3. 踩坑表

| 坑 | 原因 | 处理 |
|----|------|------|
| 控制台烧钱、本机账本很小 | 同 Key 多进程/多机/公网聊天在用 | 远端清 Key、关 8093、换新 Key、分清落点 |
| 引擎页 Key 空以为没花 | 聊天走 DSH credentials | 明确两套入口 |
| DSH Key 清空成 `""` | 宿主启动崩 | 必须有效 Key 或明确禁用路径 |
| 按月主图仍是 00:00 轴 | 误做成「整月同时段累加」 | 改为逐日双柱（跨日改完） |
