## 3. 踩坑表

| 坑 | 原因 | 处理 |
|----|------|------|
| 交付截图有文件、资料库没有 | 只接 `ldj`，当日任务在 `ccj-*` | 打开资料库扫 cursor-coding jobs |
| 「员工工时」点不开会话 | 曾手工 `dev:ldj-recover-hours` 无 DSH uuid | 说明补录壳；真实会话用 `session-…` |
| 资料库打开卡、双倍扫盘 | status 与 library 都 sync | status 只读计数；library 节流 |
| `···` 气泡被裁 | 绝对定位落在 overflow 容器内 | `position:fixed` 按按钮坐标 |
| 部分入库后永远漏文件 | backfill「已有任一 code_file」即 skip | 对照候选路径补缺 |
| 同机多账号抢 8D/ccj | upsert 改写 `user_id` | 已有主人则拒绝改归属 |
| 推送 HTTP2 framing | GitHub HTTPS/HTTP2 偶发 | `http.version=HTTP/1.1` 重推成功 |
