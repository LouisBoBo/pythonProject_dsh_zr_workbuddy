# ZR-WorkBuddy 周报 · 2026-09-07 ~ 2026-09-13

**汇报人：** 何博  
**项目：** ZR-WorkBuddy（工作助手）  
**周期：** 第 37 周（9 月 7 日周一 ～ 9 月 13 日周日）  
**给谁看：** 项目领导  

---

## 一、本周结论（先看这三段）

1. **员工侧已经能当产品用：** Mac 桌面一体包可拖进「应用程序」安装；装上就能聊、能配密钥、能走写码/审码/提交/部署；升级安装包不会冲掉用户自己装的功能。现场验收：引擎、DSH 插件中心、桌面安装后使用均通过。  
2. **交付不再「嘴上成功、界面没有」：** 写码声称「已上菜单」但浏览器没有菜单的问题已堵住；写码 / 审码 / 提交 / 部署四条线会话互不串、刷新不丢。  
3. **架构收口：** 本仓不再塞 DeepSeek Studio 源码（约 8000 个文件），聊天壳改走发行版 `dsh`；业务仍在引擎 + 热插拔功能，没有另起一套桌面框架。版本标签 **`v0.2.18`** 已推远端，可按标签回退。

## 二、本周做成了什么

### 1. 桌面一体包（给不会配开发环境的人）

| 事项 | 结果 |
|------|------|
| 连续打磨安装包 | 从缺模块、选不了目录、插件市场要全局 pnpm，修到 **0.2.18** 可安装可用 |
| 安装方式 | 做成正规 DMG：打开后把应用拖进「应用程序」，不是只弹出一个图标 |
| 升级不丢数据 | 本机密钥 / 工作区配置保留；用户后来在功能页自己装的能力，升级后也会填回去 |
| 安全 | 升级拷贝不跟随软链、限制路径和体积，避免把不该进的文件带进安装目录 |

**验收：** 本机安装 0.2.18 DMG 后正常使用。

### 2. 写码、删菜单、部署（给业务研发）

| 事项 | 结果 |
|------|------|
| 写码过程可见 | 进度卡能出思考过程，不再干等；工具路径不再刷满屏幕 |
| 删除菜单 | 过程跟 Cursor，结论跟引擎落盘，清单与结论对齐 |
| 往普通业务仓部署 | 中软 `pythonProject_zr_aicoding` 预发：先构建前端再同步，后端同步后重启服务，页面和接口都能更新 |
| 「已上菜单」假成功 | 根因是菜单配置文件没被同步却仍报成功；现已强制同步并验收失败即失败 |
| 四条车道隔离 | 写码 / 审码 / 提交 / 部署各自会话，刷新可恢复，互不覆盖 |

### 3. 稳定性与安全

| 事项 | 结果 |
|------|------|
| 聊天红条 `reading prepare` | 根因是工具库被装了两份；已自动对齐，装市场插件后可复发即再修 |
| 写码与 DSH Cursor 写码抢确认卡 | 做成互斥：开哪边用哪边，避免两张卡叠在一起 |
| 沙箱与人确认 | 写码开工仍须人点确认（引擎可验证），路径不允许随便传绝对路径开跑 |
| Git 远程地址 | 界面不再露出带 Token 的仓库地址 |

### 4. 仓库与发布纪律

- 拿掉同仓 DeepSeek Studio 源码树：日常不改 DSH 内部，聊天壳用官方发行版即可。安装包体积几乎不变（大头是内嵌 Python 引擎和 `dsh` 运行时，本来就不是那棵源码）。  
- 文档按产品 / 架构 / 安全 / 功能 / 运维分册，方便交接。  
- Git：`hebo` 分支已推送；标签 **`v0.2.18`**。

## 三、怎么验收（领导可按这个看）

| 要看什么 | 看哪 |
|----------|------|
| 业务功能（查数、配置、写码部署） | 引擎网页 `http://127.0.0.1:8000` |

两条通道不要混：WorkBuddy 自己的功能走引擎「功能插件」；DSH 生态包走插件中心。

## 四、风险与未做

1. **安装包约 1GB（压缩后约 300MB+）**：一体包必须内嵌引擎、`dsh`、Node，换 Tauri 壳也减不了多少。若要明显变瘦，需另开「是否还内嵌完整聊天壳」的产品取舍。  
2. **未做 Apple 公证、仍是默认图标**：第一次打开需右键「打开」；品牌仍是 DeepSeek 默认皮（换 Logo 不必改 DSH 内核，走官方插槽即可）。  
3. **桌面插件中心**用的是社区市场组件，不是官方 Studio 那一套；生态插件能装能用，但体验与官方桌面不完全同一套皮。  
4. **写码结论「改动文件」与真实落盘再对齐**、以及供应链上市场插件对工具库的依赖，仍可后续补，不挡当前交付。

## 五、下周建议（供拍板）

1. 维持现架构：桌面继续 Electron 套发行版 `dsh`，业务继续只进引擎和热插拔功能；**不**另起 Tauri 重做一遍。  
2. 若要更像自家产品：优先图标、公证、聊天壳品牌位（Logo / 探索语）。  
3. 生产/预发继续按「改哪发哪」；验收继续认引擎探活和真实页面，不认「聊天里说已上线」。
