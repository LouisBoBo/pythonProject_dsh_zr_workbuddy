## 一、本周目标（给领导）

在 **`v0.2.18` 可装可用** 的前提下，做四件事：

1. **稳住交付：** 四车道（写码 / 审码 / 提交 / 部署）按现网口径再跑一轮，确认没有回潮。  
2. **补体验缺口：** 写码结束「改了哪些文件」与真实落盘对齐（上周暂缓项）。  
3. **dsh 包一键升级：** 发行版 `@deepseek-ai/dsh` 能一条命令升到指定版本（开发壳 + 桌面包钉版本），不必再拷 Studio 源码。  
4. **产品皮（需拍板）：** 若本周要更像中软自己的助手，优先换桌面图标 + 聊天壳品牌位；Apple 公证另开，不和功能混在一包里赶。

不在本周范围：换桌面框架、瘦身安装包、重做官方插件中心。

## 三、明确不做

- 不按网上「DSH + Tauri」示例另起桌面仓。

- 不为换皮、不为升级 dsh 去编译 / 拷贝 DeepSeek Studio 源码。  
- 不以打开聊天窗口当作业务发布成功。
- dsh 一键升级只动发行版 npm 包，不把源码树重新拖进本仓。
