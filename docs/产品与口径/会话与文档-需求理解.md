# 会话记录与会话文档 · 需求理解

> **状态**：**已定稿**（第三轮：会话正文进库可摘要；报告进空间可自管；P0 保留清理）  
> **施工图**：[会话归档方案.md](../功能实现/会话归档方案.md)  
> **约束**：不另造聊天窗；不改 DSH；续聊权威仍是 DSH 本机 jsonl；不上云

---

## 0. 大白话

1. 平时 **DSH 新开聊**；很少靠历史续聊。  
2. **会话正文进本机数据库**（可以是**摘要/摘录**，方便管，不要求把整份 jsonl 无损塞进库）。  
3. **报告正文进「我的空间」**，自己能打开、删除、清理。  
4. **P0 就要保留天数 + 清理**，避免本机越堆越多。  
5. 不做换机云同步、不做第二个聊天壳。

---

## 1. 存哪（对照「是不是都在库里」）

| 东西 | 存哪 | 说明 |
|------|------|------|
| 会话正文 / 摘要 | **SQLite 进库** | 档案；不是给空间里续聊用 |
| 报告正文 | **我的空间**（文件 + 库元数据） | 用户自管 |
| 图表等大文件 | 空间文件目录 | 不进 BLOB |
| 当下接着聊 | 仍看 DSH `session.jsonl` | 删空间档案默认不删 DSH 会话 |

---

## 2. 拍板摘要

| 轮次 | 结论 |
|------|------|
| 云 + 换机续聊 | **否决** |
| 本机空间 | **做** |
| 会话正文 | **进库，可摘要** |
| 报告正文 | **进我的空间，可自管** |
| 保留清理 | **P0 就要** |
| 工期 | 一人约 **2～3 周**（因正文+清理略增） |

---

确认施工图后开工：库表（含 `body_text`）→ 报告进空间 → 会话摘要投影 → 保留清理 → 引擎页。
