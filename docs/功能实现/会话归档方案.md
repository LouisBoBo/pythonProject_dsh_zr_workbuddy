# 本机「我的空间」· 会话记录与会话文档实施方案

> **状态**：P0 已落地（会话摘要进库、报告正文进空间、保留清理、`:3081` 底栏「资料库」）  
> **需求口径**：[会话与文档-需求理解.md](../产品与口径/会话与文档-需求理解.md)  
> **配合**：[DSH会话与记忆分层](../架构与选型/DSH会话与记忆分层.md) · [四车道会话契约](../架构与选型/四车道会话契约.md) · [企业级安全加固方案](../安全/企业级安全加固方案.md)  
> **验收**：`:3081` 底栏「资料库」按会话列出文档、全屏预览、下载/删除/清理；**不以换机续聊为成败**  
> **明确不做**：云同步、换机续聊、第二聊天壳、用空间表给 Agent 续聊、Postgres、改 DSH 源码

---

## 1. 一句话

DSH 仍负责**当下怎么聊**；「我的空间」负责**事后怎么管**：会话正文（可摘要）进本机库、报告正文进空间并由用户增删清理，带保留策略，避免本机无限涨。

---

## 2. 产品口径（现行）

| 要 | 不要 |
|----|------|
| 会话正文**进 SQLite**（P0 允许**摘要**，不必逐字全量） | 用这份正文在空间里「接着打字」（续聊仍去 DSH 新开/点旧会话） |
| 审码等**报告正文进我的空间**，用户可打开/删除/清理 | 每次让用户指定本地文件夹 |
| **P0 就有**保留天数 + 手动清理 | 换电脑同步、云盘 |
| 同机按登录用户隔离 | 第二聊天壳；把整仓工程无差别拷进空间 |
| 写码成功后**本任务改动∩已同步**的源码副本进空间（白名单扩展名、跳过密钥） | 未改动文件、密钥/`config.yaml`、交付摘要进库 |

| 类型 | 存哪 | 用户怎么管 |
|------|------|------------|
| 会话正文 / 摘要 | `catalog.sqlite`（档案，非 L1） | 列表查看；可删该会话档案；受保留策略 |
| 报告正文 | 空间文件 + 库内元数据（或库内文本） | 「我的空间」打开/删除；受保留策略 |
| 图表等二进制 | `engine/data/space/files/…`（或指针） | 同上 |
| 写码改动源码副本 | 空间 `files/…/code/` + 元数据 | 按会话查看/删除；原工程文件仍在用户项目目录 |

---

## 3. 和「是不是都在数据库」一句话

- **会话**：正文/摘要 **在库里**（方便管理、检索列表）。  
- **报告**：正文 **在我的空间**（库记账 + 正文落空间存储），用户自管。  
- **续聊真相**仍是 DSH 的 `session.jsonl`，空间里的会话正文是**档案副本/摘要**，删掉空间记录**不保证**删掉 DSH 左边那条（P0 可不联动删 DSH；UI 写清楚）。

---

## 4. 架构（L4 档案，不当 L1）

```text
L1  聊天权威     DSH ~/.dsh/sessions（同机刷新/续聊）
L2  执行账本     Job / 原 reports 路径（可仍写一份）
L3  加速缓存     localStorage
L4  我的空间     catalog.sqlite（会话摘要/正文档案）
                 + space/files（报告正文等）
                 + 保留清理
```

```text
聊完 / 审码完成
  → L1/L2 照旧
  → L4：投影会话正文（可摘要）写入 sqlite
  → L4：报告正文写入「我的空间」并挂 session_id
  → 用户在引擎页管理；到期或手动清理
```

门禁：

- 禁止 Agent / 聊天主路径读 L4 当历史续聊。  
- 允许从 DSH jsonl **只读投影**进 L4 档案。  
- 删 L4 ≠ 必须改 DSH（P0 默认不联动）。

## 5. 存储选型

| 项 | 结论 |
|----|------|
| 目录 + 会话摘要/正文 | **SQLite** `engine/data/space/catalog.sqlite` |
| 报告正文 | **空间内文件** `engine/data/space/files/{user_id}/reports/{id}.md`（或 `.json`）；库表只存元数据 + 可选短摘要 | 
| 大图 PNG | 文件，不进 BLOB |
| 云 / Postgres | 不做 |

P0 会话正文策略：**可摘要**——例如：

- 保留最近 N 轮 user/assistant 纯文本，或  
- 一轮结论式摘要（标题 + 要点 + 产物列表），单会话入库上限（如 64KB 文本）。  

超出截断并标注「已截断」。不必 P0 就把整份 jsonl 无损搬进库。

## 6. 数据模型（要点）

### 6.1 `sessions`

| 列 | 含义 |
|----|------|
| `id` / `source` / `title` / `user_id` / 时间 | 同前 |
| `body_kind` | `summary` \| `excerpt` \| `full_text`（P0 主用 `summary` / `excerpt`） |
| `body_text` | 会话正文或摘要（进库） |
| `body_truncated` | 是否截断 |
| `dsh_path` | 可选，对账用 |

### 6.2 `artifacts`

| 列 | 含义 |
|----|------|
| `id` / `session_id` / `user_id` / `kind` / `title` | |
| `relpath` | 相对 `engine/data/space/files/…`（报告正文等） |
| `summary` | 可选一句话 |
| `bytes` / `created_at` | |

报告：**正文文件在空间**；打开读文件，不依赖 L2 原路径也能看（入库时拷贝或写入空间副本）。L2 `code_review/reports/` 可仍保留一份给 Job API，空间以副本为准做「用户资产」。

### 6.3 保留配置（P0）

`config.yaml` / 配置中心「我的空间」：

```yaml
space:
  retention_days: 90          # 0 = 不自动删
  max_session_body_chars: 65536
  auto_purge_enabled: true    # 启动或每日轻量扫过期
```

## 7. 写入时机

| 事件 | 动作 |
|------|------|
| 审码报告保存 | 写空间报告正文文件 + artifacts 行；补 session/user |
| 写码 Job 成功 | 交付小结进 artifacts；**仅本任务 `changed_files ∩ synced_files` 的源码副本**（白名单扩展名、跳过密钥）挂同一会话；未改动文件不入库 |
| **打开资料库** | fail-soft：① 扫描 `~/.zhongruan/pcb-8d-drafts/*.md`；② 从本机 DSH `session.jsonl` 抽出**像文档的助手回复**（测试用例/方案等），绑定该文件的 `session-uuid` |
| 会话有实质进展 | 从 DSH jsonl **投影**更新 `body_text`（摘要/摘录）；失败只打日志 |
| 用户删除 | 删 artifacts 文件 + 行；删 session 行（及下属文档，确认二次） |
| 保留任务 | 删过期 session/artifacts + 文件 |

`chat_log.jsonl` 不导入。

## 8. API（P0 必备）

Tags：`我的空间`。须登录。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/space/sessions` | 列表 |
| GET | `/api/space/sessions/{id}` | 含 `body_text`（摘要/正文档案）+ artifacts |
| DELETE | `/api/space/sessions/{id}` | 用户删会话档案（及可选级联文档） |
| GET | `/api/space/artifacts` | 按文档列表（含报告） |
| GET | `/api/space/artifacts/{id}` | 报告正文等 |
| DELETE | `/api/space/artifacts/{id}` | 用户删单份文档 |
| POST | `/api/space/purge` | 按保留策略清理；或 `dry_run` |
| GET | `/api/space/status` | 占用、保留天数、条数 |
| POST | `/api/space/ingest` | 回填 |

导出 zip：P0 建议带上（便于「先导出再清理」）；若工期紧可与清理同迭代后半完成。

## 9. 界面（P0）

产品入口 **`:3081`**：左侧底栏「资料库」（与「用量」同级，mes-bridge 弹层）。按会话列出其下文档；点文档全屏预览。

1. **按会话**：看标题、时间、摘要预览；点开看正文档案；删除。  
2. **按文档**：报告等；打开正文；删除。  
3. **清理**：显示保留天数、当前占用；「清理过期」；可选改保留天数（进配置中心）。  
4. 文案：「仅本机；空间里的会话是档案/摘要，续聊请用 DSH 新开或点原会话。」

---

## 10. 安全

- 路径守卫、Bearer、按 `user_id` 隔离、脱敏同前。  
- 删除/清理是变异接口：同源/登录校验（对齐现有 HITL/Origin 惯例，空间删除不要求写码级 nonce，但须登录且只能删自己的）。  
- `body_text` / 报告禁止回显 Key。

## 12. 验收话术

1. 聊/审码后，「我的空间」能看到会话摘要（或摘录）和报告正文。  
2. 用户能删除某份报告、某条会话档案。  
3. 改保留天数为很短 → 触发清理 → 过期条目消失、磁盘占用下降。  
4. 删空间档案后，DSH 仍可同机点开原会话（若不做联动——符合 P0）。  
5. 另一用户看不见；空间失败不影响审码成功。
