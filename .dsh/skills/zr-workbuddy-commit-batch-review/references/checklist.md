# 提交批审检查面（gate-90 本批版）

> 与 `code-review` Skill 的 gate-90 **同源**；范围仅限本批文件，不做全仓 list。

## 1. 必扫（本批内）

| 维度 | 关注点 | 典型阻断 |
|------|--------|----------|
| 敏感路径 | `.env`、密钥、私钥、凭证 JSON | P0 |
| 注入 / RCE | SQL 拼接、`eval`、命令执行、反序列化 | P0 |
| 密钥硬编码 | password/secret/api_key 明文 | P1 |
| 认证授权 | 管理接口裸奔、越权读写 | P0/P1 |
| 数据安全 | 日志打印 token/密码/身份证 | P1 |
| 正确性 | 明显空指针、错误 ID 覆盖、竞态写 | P1（严重可 P0） |

本批若含 `package.json` / `requirements.txt` / 配置文件：顺带看已知高危依赖与 debug 开关。

## 2. 严重度

- **P0**：可远程利用、明文密钥进仓、敏感路径 —— 阻断提交
- **P1**：硬编码密钥、严重逻辑/并发风险 —— 阻断提交
- **P2**：TODO、风格、可 formatter 修复 —— 警告，不阻断

## 3. 不在本 Skill 范围

- 全仓依赖审计、跨文件架构评审 → 走 `code_review` 车道
- 四段式长报告 → 走 `ide-code-review` / `git-code-review`
